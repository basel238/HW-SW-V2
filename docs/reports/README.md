# Benchmark reports

The report sources, evidence registry and generated PDFs in this directory support the required root-level report_nbody.txt and report_raytrace.txt files. The PDFs and TXT exports share one content source. Evidence is separated into measured target-VM results, local correctness checks, and explicitly assumed hardware estimates. Generated PDFs are supplemental to the filenames required by the assignment.

Final correctness policy: bit-identical benchmark outputs/state at successful call boundaries. Approximate sqrt variants remain optional experiments. Upstream reference sources are immutable. No Git operations are part of authoring or validation.
